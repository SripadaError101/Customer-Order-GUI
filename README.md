Customer Shopping GUI

A simple web page to place snack, chocolate and beverage orders and see an order history table. Built with plain HTML, CSS and JavaScript.

How to run

Open index.html in any browser. No installation needed.

How to use
Enter a Customer ID
Choose a product
Enter a quantity
Click PlaceOrder

The order shows up in the Order History table with its total amount in ₹.

Note: Orders are not saved, so refreshing the page clears the history.
